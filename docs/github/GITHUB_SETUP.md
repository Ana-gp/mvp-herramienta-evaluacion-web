# Preparación del repositorio GitHub

## Nombre

`mvp-herramienta-evaluacion-web`

## Descripción

> MVP de herramienta para evaluación web mediante señales técnicas de SEO, accesibilidad y AI Search, desarrollado mediante Vibe Coding con control de versiones, validación y trazabilidad.

## Configuración recomendada

1. Crear el repositorio con el nombre anterior.
2. No inicializarlo con README, licencia o `.gitignore` si se va a importar este baseline completo.
3. Asociar el remoto al repositorio creado.
4. Publicar `main` y los tags.
5. Publicar `develop` como rama de trabajo.
6. Configurar protección de `main` para exigir revisión de PR y checks de CI antes de integrar cambios relevantes, cuando la política del proyecto lo permita.
7. Crear una release correspondiente a `v0.1.0-baseline` con las notas de `docs/validation/RELEASE_NOTES_v0.1.0-baseline.md`.

El commit `640a032` es el commit real de importación del baseline. No debe presentarse como un commit histórico del desarrollo anterior.
