# Trazabilidad

La matriz principal está en `criterion_traceability.csv`.

La cadena de gobierno es:

**V1 → funcionalidad → código → prueba/caso → evidencia → resultado → release**

La matriz distingue expresamente el estado histórico de las nuevas acciones del repositorio.

## Regla

Estar presente en `src/app.py` no significa estar validado. La validación requiere una ejecución y evidencia asociada.
