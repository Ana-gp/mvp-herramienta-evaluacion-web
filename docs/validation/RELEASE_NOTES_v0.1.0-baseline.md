## Qué contiene

- Baseline G24 del MVP.

## Qué significa

Esta release representa el **baseline de importación para el control formal de versiones**. No es una afirmación de producción ni una reconstrucción del historial anterior.

## Limitaciones

- No valida los 87 criterios V1.
- No demuestra conformidad WCAG.
- No demuestra citación por sistemas de IA ni ranking.
- No demuestra ausencia global de falsos positivos/falsos negativos.
- No constituye certificación de seguridad de producción.
