# Tests

Esta carpeta distingue claramente material histórico de controles actuales.

- `fixtures/`: fixtures controlados asociados a validaciones históricas.
- `historical/`: espacio reservado para material de prueba histórico si se incorpora de forma explícita.

Las validaciones G25 no se recrean como si hubieran sido ejecutadas por este repositorio en la fecha de importación. Sus evidencias se conservan en `evidence/historical/`.
